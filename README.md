# 鶴亀宇宙

## 作品概要

人類が絶滅した遠い未来を舞台に、
宇宙を自由に飛行できる「鶴」を操作し、
宇宙を探索しながら宇宙生物の写真を撮影し、
図鑑を完成させていくゲームを制作しています。

## 開発環境

- Unity 2022.3.62f3
- C#
- Blender
- Inkscape

## 実装内容

- 3Dプレイヤー移動
- TPS視点による探索
- FPS視点への切り替え
- Raycastを利用した写真撮影判定
- ScriptableObjectによる生物データ管理
- 図鑑システム
- メニュー・シーン遷移
